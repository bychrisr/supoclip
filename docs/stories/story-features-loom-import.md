# Story: Loom Import

- **Epic:** epic-features.md
- **Fase:** FASE 2 - Differentiation
- **Priority:** P2
- **Estimate:** 12h

## Problem

Loom é usado para gravações de tela quick, tutorials e updates de equipo. Importar do Loom evita re-download.

## Solution

Implementar integration com Loom API para:
1. OAuth com Loom
2. List recordings da conta
3. Import direto para processamento

## Scope

- **In:** Loom recordings
- **Out:** Direct upload from Loom

## Tasks

1. [ ] Loom Developer app setup
2. [ ] Loom OAuth integration
3. [ ] Recordings list API
4. [ ] Import flow UI

## Acceptance Criteria

- [ ] Botão "Import from Loom"
- [ ] OAuth flow com Loom
- [ ] Lista de recordings
- [ ] Import direto funciona

## Dependencies

- Loom Developer API
- OAuth base
